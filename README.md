# SoundCloud Playlist Hider

A Chrome extension that hides **"posted a playlist"** items from your SoundCloud feed, so you only see what matters.

> **Chrome Web Store review in progress.** In the meantime, install it manually in under a minute using the steps below.

## Features

- Automatically hides playlist posts from the SoundCloud feed
- Works with infinite scroll (new items are filtered as they load)
- Toggle on/off from the extension toolbar popup
- Your preference is saved between sessions
- Zero data collection — everything stays on your device

### Option B — Manual install (takes ~1 minute)

**Step 1 — Download the extension**

Go to the [Releases page](https://github.com/fdebkowski/soundcloud-playlist-hider/releases/latest) and download `soundcloud-playlist-hider.zip`.

**Step 2 — Unzip it**

Extract the ZIP to any folder on your computer, e.g. `Downloads/soundcloud-playlist-hider`.

**Step 3 — Load it in Chrome**

1. Open Chrome and go to `chrome://extensions`
2. Turn on **Developer mode** using the toggle in the top-right corner
3. Click **Load unpacked**
4. Select the folder you extracted in Step 2

The extension icon will appear in your toolbar. That's it.

**Step 4 — Use it**

Navigate to [soundcloud.com/feed](https://soundcloud.com/feed). Playlist posts are hidden automatically. Click the extension icon to toggle the filter on or off.

> **Note:** Because this is a manual install, Chrome may show a warning that the extension is not from the Web Store. This is normal for developer-mode installs — the source code is fully open and auditable here.

---

## Usage

Click the extension icon in the Chrome toolbar at any time to toggle the filter on or off. The setting is remembered between browser sessions.
