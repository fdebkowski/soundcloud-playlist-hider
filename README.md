# SoundCloud Playlist Hider

A Chrome extension that hides **"posted a playlist"** items from your SoundCloud feed, so you only see what matters.

## Features

- Automatically hides playlist posts from the SoundCloud feed
- Works with infinite scroll (new items are filtered as they load)
- Toggle on/off from the extension toolbar popup
- Your preference is saved between sessions
- Zero data collection — everything stays on your device

## Install

**From the Chrome Web Store:**  
[Install SoundCloud Playlist Hider](#) *(link coming soon)*

**Manual (developer mode):**

1. Clone this repo or download the ZIP
2. Go to `chrome://extensions`
3. Enable **Developer mode** (top right)
4. Click **Load unpacked** and select this folder

## Usage

Navigate to [soundcloud.com/feed](https://soundcloud.com/feed). Playlist posts are hidden automatically. Click the extension icon in the toolbar to toggle the filter on or off.
